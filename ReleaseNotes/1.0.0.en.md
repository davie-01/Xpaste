## XPaste 1.0.0

The first release.

- Clipboard history: text, rich text, images, links, colors and files, kept on this Mac. Items that password managers mark as concealed are skipped, and you can ignore specific apps.
- A panel at the bottom of the screen: press ⇧⌘V to open it, Return or double-click to paste, ⇧Return to paste as plain text, ⌘1–⌘9 to paste the first nine items.
- Search and filters, including text recognized in images; filter by type, source app or Pinboard.
- Pinboards: keep frequently used items in named, colored Pinboards that never expire.
- Preview with Space, and edit text, links, colors and images.
- Paste Stack: press ⇧⌘C to collect items, then ⌘V pastes them back in order.
- An optional local MCP server for AI tools such as Claude Code, Codex and Cursor, off by default.
- In-app updates: checks once at launch and only tells you when there is a new version.
